# Project Depot 0.3.0

Release date: 2026-10-30. Tag `v0.3.0`.

The first Depot release numbered by hand (see [versioning](../VERSIONING.md)): the minor number goes up
because this release adds and removes features. The historical baseline is still openOMSI `v0.2.16`
(`c85b2e0dda13d219fd12d0496c653d20cdb54145`), and no later openOMSI commit was imported wholesale.
Full list of pull requests: [`v0.2.52...v0.3.0`](https://github.com/OmsiModsBR/depot/compare/v0.2.52...v0.3.0).

## Download

- `depot-0.3.0-windows-x64.zip`: game and launcher tools (Windows x64 only).

No dedicated-server, ARM64, Linux, macOS or Android package is included. Project Depot needs an
original OMSI 2 installation and includes no game content.

## What changed

Details are in [CHANGELOG.md](../../CHANGELOG.md).

- **DirectX 9 (D3D9Ex) renderer, off by default:** Settings → Graphics API offers "DirectX9 (D3D9Ex)"
  on Windows ("Automatic" never picks it). It draws the scene, materials and their maps, lamps and
  tile light maps, the sky, light coronas, smoke and particles, the interface and the maps, with an
  optional snowfall. Graphics stays at Vanilla under it.
- **New in-game interface:** a new Esc menu and the pages behind it, the Alt bar (a tap of Alt) with
  Add vehicle and the rest of its buttons, a new loading screen, an end-of-trip report, the
  redesigned information bar (Shift+Y) with several layouts, and windows in the Windows 11 look.
- **Navigator and city map:** compass, terrain view with contour lines, street names under the
  pointer, lines panel with timetables, top-view minimap option, new vehicle pictograms.
- **Launcher redesign:** Maps as the start page, Vehicles grouped by manufacturer, Profile and
  Sessions in one page, a Timetable planning page, Setup and Settings rebuilt, accent colours, the
  sidebar or a top bar, and a launcher that opens at once.
- **Diagnostics:** integrity check of maps and vehicles (also against a baseline folder), the AI
  traffic tab with editing of a map's AI lists and parking lists, and a detailed log switch.
- **Vehicle physics:** the refactor is complete; the weight of the passengers aboard the player's
  bus is added; steering linearity on by default; `[momentofintertia]` read in the y-up frame;
  articulated buses no longer fold into an L at speed and their bellows no longer open a gap on
  grades; AI vehicles steer by their own `.bus` files.
- **Passengers:** they no longer board an articulated bus by its last door alone, keep the height of
  a high platform, and complain again when the saloon is too dark (#179).
- **Performance:** no more drop to a few frames a second while paused in traffic (#43).
- **Removed:** LAN play, the dedicated server, voice chat and the plugins, switched off since the
  first Depot release, are removed from the repository; also the `--physics simple` option.
- **Content safety:** a content file or map package can no longer point the game at another drive
  or computer; mods install from a `.zip` only.

## Known limitations

- **Parity:** the physics changes are intended to approach OMSI 2, but most are supported only by
  automated tests and traces, not by a recorded comparison in the game. Treat them as not
  demonstrated 1:1.
- **DirectX 9** is new and off by default; under it the graphics options are reduced and VR is not
  available.
- The original OMSI 2 mode in the launcher is still hidden and Windows only.
- Multiplayer and plugins are gone; some leftovers (the chat box, name tags) are still in the code.
- Hardware matrix unchanged: Windows x64 package only; nothing new is qualified.

## Build and validation

The package must be built with `OPENOMSI_VERSION=0.3.0` passed explicitly, and `depot --version`
checked before packaging. The build commit, toolchain and checks are recorded on the GitHub release
by the person who builds the package.

## Rollback

Reverting to the previous release means using the [0.2.52](0.2.52.md) package, or reverting the
relevant pull requests in Git; see the [full list](https://github.com/OmsiModsBR/depot/compare/v0.2.52...v0.3.0).
