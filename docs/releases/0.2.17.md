# Project Depot 0.2.17 — rebranding only

Release date: 2026-10-09.

**This release is simply the rebranding of the project.** It derives from
openOMSI `v0.2.16` (2026-10-07), commit
`c85b2e0dda13d219fd12d0496c653d20cdb54145`.

Changes are limited to Project Depot branding, executable/package/generated-data
names, Depot repository/update configuration, independent maintenance policy and
documentation. The MIT license and internal source identifiers remain unchanged.

**No gameplay, renderer, physics, simulation, scripting or multiplayer features
or fixes are added.** Prioritizing physics/simulation evolutions and achieving
1:1 compatibility with OMSI 2 are development goals, not delivered improvements
or guarantees in this release. This is an initial release for testing; it retains
the behavior and known limitations of its historical baseline.

## Downloads

- `depot-0.2.17-windows-x64.zip`: game and launcher tools.
- `depot-0.2.17-server-windows-x64.zip`: dedicated server.

Both need an original OMSI 2 installation and include no game content.
No ARM64, Linux, macOS or Android package is included in this release.

## Build and validation

The binaries were built from Depot commit
`8edb76a8b67c9248cfc2b7ba8b09628f30c6a1fe` using Rust/Cargo 1.99.0,
the Windows x64 MSVC target, locked dependencies and release optimization without
debug symbols. `OPENOMSI_VERSION=0.2.17` was supplied explicitly.
Changes after that binary-source commit for this release are documentation only;
package documentation is updated without changing the executables.

Compilation, archive extraction, `--version` and `--help` checks passed for the
game, launcher and server binary. Full gameplay/physics/graphics/multiplayer
testing and the complete test suite were not performed at publication time.
Subsequent maintenance validation passed the full Windows release workspace
build and all 1,320 default tests (36 ignored) in Depot CI, after correcting
only a stale rebranding test expectation. The release packages and tag were
not replaced. See [validation evidence and limitations](../BASELINE-VALIDATION.md).

Upstream automatic releases remain disabled. Depot follows **stable base +
selective upstream integration**, with manually reviewed releases.
