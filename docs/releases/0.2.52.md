# Project Depot 0.2.52

Release date: 2026-10-10. Tag `v0.2.52` (`3e0d490c2eb91b928178a1175d885a607994363d`), published by
@ZaneThurston: https://github.com/OmsiModsBR/depot/releases/tag/v0.2.52

This is the first Depot release with changes to behaviour since the rebranding-only
[0.2.17](https://github.com/OmsiModsBR/depot/blob/main/docs/releases/0.2.17.md). The version number is Depot's own count; it does not mean openOMSI 0.2.52 was
imported. The historical baseline is still openOMSI `v0.2.16`
(`c85b2e0dda13d219fd12d0496c653d20cdb54145`), and no later openOMSI commit was imported wholesale.
Full list of pull requests: [`v0.2.17...v0.2.52`](https://github.com/OmsiModsBR/depot/compare/v0.2.17...v0.2.52).

## Download

- `depot-0.2.52-windows-x64.zip`: game and launcher tools (Windows x64 only).

No dedicated-server, ARM64, Linux, macOS or Android package is included. Project Depot needs an
original OMSI 2 installation and includes no game content.

## What changed

Details are in [CHANGELOG.md](https://github.com/OmsiModsBR/depot/blob/main/CHANGELOG.md).

- **Identity, security and removals:** Depot identity, security hardening, and the removal of telemetry,
  multiplayer (disabled), the in-app updater, Discord Rich Presence, and RAR/7z/ZIP extraction.
- **Outside view (F3):** independent field of view, fitted to ultrawide screens.
- **Navigator map packages:** surface, icons, regions, street names and bus lines.
- **Pusher articulation:** configurable from the `.bus`.
- **Sound:** an entry that starts playing starts at full gain.
- **Articulated buses and trailers:** every section is a body of its own (multibody).
- **Timetable:** the delay on the way follows where the bus is.
- **Terminal stops:** fill up with waiting passengers again (issue #11).
- **Launcher:** the game opens on the monitor the launcher is on; the vehicle viewer stands the bus on the floor.
- **Vehicle physics refactor:** the rigid body split into modules, one bridge to the script variables,
  `VehicleMotion` and `Dynamics`, and the older A/B switches and models removed. Bit-exact physics traces
  are the safety net.
- **Vehicle physics model changes** (each differs from the previous build, labelled `physics-delta` in its
  pull request): the tyres take the road's grip of the frame they drive in; the tyres' hold in a bend is
  measured on the bend the body turns on; driving and braking pitch the body from the first axle's wheel
  radius. In the test scenarios the largest pitch change is 0.2 degrees.
- **Wheel seating** (`seat_wheels`) removed.
- **Documentation and site:** comments and docs describe observable behaviour only; project site on GitHub Pages.

## Known limitations

- **Not validated against real content in the game:** multibody articulated buses and trailers, navigator
  map packages, terminal-stop passengers and the sound change were checked by automated tests only. The
  `OMSI_KINEMATIC_TRAILERS=1` fallback no longer exists; to go back, use [0.2.17](https://github.com/OmsiModsBR/depot/blob/main/docs/releases/0.2.17.md).
- **Parity:** the three physics model changes are intended to approach OMSI 2 but no recorded black-box
  comparison supports them yet. Treat them as not demonstrated 1:1. Automated traces show numerical
  stability, not parity.
- The offscreen golden test has not been blessed on a machine with a graphics adapter.
- The dedicated server, multiplayer and plugins stay disabled.
- Hardware matrix unchanged: Windows x64 package only; nothing new is qualified.

## Not in this release

The passengers-standing change (a free seat first, pull request #55) and the macro-refactoring draft
(pull request #51) were still open at the tag.

## Build and validation

The release notes published on GitHub do not record the build commit, toolchain, test results or the
check of the package. Those must be completed by the person who built the package before this release
is treated as validated; see [validation evidence and limitations](https://github.com/OmsiModsBR/depot/blob/main/docs/BASELINE-VALIDATION.md) for the
0.2.17 evidence.

## Rollback

Reverting to the previous release means using the [0.2.17](https://github.com/OmsiModsBR/depot/blob/main/docs/releases/0.2.17.md) package, or reverting the
relevant pull requests in Git. A bullet above can span several pull requests (for example the
launcher items, #13 and #18, and the physics refactor, #27 and #29 to #32), so check the
[full list](https://github.com/OmsiModsBR/depot/compare/v0.2.17...v0.2.52) before reverting one.
